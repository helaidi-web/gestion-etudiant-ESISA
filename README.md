# Gestion des Étudiants ESISA

Application web de gestion complète des étudiants pour l'école ESISA.

## Fonctionnalités

- ✅ Ajouter, éditer et supprimer des étudiants
- 📊 Affichage des statistiques
- 🔍 Recherche et filtrage des étudiants
- 💾 Stockage local des données
- 📱 Interface responsive

## Technologie

- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage API

## Installation

1. Cloner le dépôt
```bash
git clone https://github.com/helaidi-web/gestion-etudiant-ESISA.git
```

2. Ouvrir `index.html` dans un navigateur

## Déploiement

Ce projet est configuré pour être déployé sur Vercel.

```bash
npm install -g vercel
vercel
```
